# Image prompts for realistic test forms

**How to use**
1. Open ChatGPT, start a **new chat for each prompt** (so styles don't bleed into each other).
2. Paste one prompt exactly as written. Turn on thinking if it's offered.
3. When the image appears, download it and save it in this folder (`Athena/incoming-samples/`) with the file name shown, e.g. `ai-01-clean.png`.
4. If the image looks like a drawing/illustration instead of a photo, reply once: **"Make it look like a real, slightly imperfect smartphone photo, not an illustration. Keep every written value exactly the same."**
5. Don't worry if a number comes out slightly different from the prompt: I check every image and write the answer key from what is actually visible. Only redo it if the text is a garbled mess.

When you're done (or ChatGPT hits its daily limit), tell me and I'll take it from there.
